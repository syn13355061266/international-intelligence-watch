## 单篇精选：旧公式

五轴均为0–10分：实质影响sig、信息增量nov、证据强度cred、共振面reson、决策价值act。

`B = round(5.5×sig + 1.5×nov + 1.5×cred + reson + 0.5×act)`

原来直接把B作为单次精选分。每篇独立评两次，`S1+S2 ≥ 2×门槛`才入选；显示分数为平均数向下取整。门槛为T1=60、T1_5=65、T2=76。

## 新公式：涉我性30%，全球大事保护

增加涉我性C（0–100）：没有事实支持为0；有全球传导线索为1–30；具体间接影响31–60；明确对华政策、海外中国权益或四外在华活动61–85；直接、重要且已实施或明确宣布的中国安全与利益影响86–100。

`S普通 = round(0.70×B + 0.30×C)`

若模型标记为全球重大事件，且 **B≥80、sig≥8、cred≥7、nov≥5**：

`S = min(质量上限, max(B, S普通))`

其余为 `S = min(质量上限, S普通)`。

- cred≤3、nov≤2或sig≤2：最高30分；sig≤3：最高40分；否则最高100分。
- 单纯出现“中国”、由中国媒体报道、营销或一般背景提及中国不算实质涉我。
- C>0必须附原文逐字证据，后端验证引文确实存在于标题或正文中；不能引用评分指令。五轴与C由模型判断，后端计算总分、保护和上限，不接受模型自由报一个总分。
- 两次评分结构、来源门槛、人工覆盖、回执和预算机制保持；预筛明确保留外国重大事件，压住无中国关联且无跨境/系统性价值的地方琐事。

| 场景（示意输入，非实测准确率） | B | C | 新分数 |
| --- | ---: | ---: | ---: |
| 质量合格、明确对华限制 | 70 | 100 | 79 |
| 同等基础质量、普通无关外国新闻 | 70 | 0 | 49 |
| 证据充分的全球危机，满足保护条件 | 90 | 0 | 90 |
| 证据不足的涉华传闻，cred≤3 | 任意 | 100 | ≤30 |

这是按用户目标设置的首版规则；不是已经用用户标注语料校准的统计模型。入选门槛未凭感觉改动，后续可用100–200条用户标注样本在SelectBench校准。

## 事件热点重要性

原来的基础分及额外分保留：

`H0 = round(0.55×严重程度 + 0.20×来源等级 + 0.15×独立印证 + 0.10×新鲜度) + 外交加分 + 实体行动加分`

各项基础指标为0–100；额外分最多38，因此H0可能超过100。来源去重、96小时材料范围、24小时衰减及证据限制见 `intelligence.md`。

新事件分 `H = round(0.70×H0 + 0.30×C事件)`。C事件取当前有效、非历史资料中每篇两次涉我评分均值的最大值，避免转载数量把相关性堆高。

由当事方/一级来源或至少两个等级1–2独立来源建立证据，并达到high/critical的事件，取 `max(H0,H)`，保留全球重大事件原有排名竞争力。没有涉我性评估的旧数据保留H0并标记“待评估”，不会把未知当作0。

热点候选的多主体要求、最多10条、同分按讨论热度与更新时间、公开许可和撤回规则保持不变。单篇精选与热点重要性是两道不同计算。

## 生效范围与部署
