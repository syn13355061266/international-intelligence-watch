# 国际情报观察：配置与启用

最初四个专题已按用户批准扩展为十个国家安全主栏目；稀土、石油、供应链、金融保留为细分主题。国别与会务目录已加入，详见`intelligence-expansion.md`。站点的行业包、筛选、归组、日报和机器出口都围绕国家安全、国际合作与竞争、地缘政治、社会动荡的具体影响编写。

## 排序与精选

热点榜按事件重要性优先，同分再看讨论热度和更新时间：

`基础分 = round(严重程度×0.55 + 来源等级×0.20 + 独立来源×0.15 + 新鲜度×0.10)`

- 严重程度：critical=100、high=75、medium=50、low=25、info=0。模型只负责有边界的事件标签；最终分数由代码计算。
- 来源等级：1=100、2=75、3=50、4=25，取事件中最强来源。该等级保存在信源配置 `_intelligence.sourceTier`，与决定精选门槛的 T1/T1_5/T2 分开。
- 印证：每个独立发布主体20分，最多5个。相同媒体的 RSS、地区版与能识别的 Telegram 入口共用 `signal_group_id`；Google 通用搜索同属一个搜索入口，不把每个关键词当独立媒体。此项表示独立报道覆盖，不能自动证明说法为真。转载关系仍需运营者审核调整。
- 新鲜度：按原始发布时间在24小时内线性衰减；不能用发现时间替代发布时间。无日期、未来超过1小时或超过96小时的证据不进入这版重要性计算。
- 额外加分：同一实体/行动在24小时内有至少2个等级1–2的独立来源，并有明确外交敏感事件标签，外交加18分；实体/行动加 `min(来源数,5)×4` 分。3个来源时最低提升到high。总分可超过100，最高138。
- 历史回顾不获得危机严重程度或外交加分；不明日期、未经证实的单方声称不应被模型提升为高危。单一非权威来源还会在代码中被限制到medium。

热点候选仍需要至少两个参与主体与一条可公开的正式报道，最多显示10个事件。单一官方重大公告仍可进入精选和日报，但不单独进入这个多源热点榜。事件归组错误会影响重要性，应在后台纠正。

热点页公开显示基础分、四项分值、额外加分、独立来源数和待分类状态。讨论热度与热度趋势保留，表示传播变化。网站 API 返回重要性；既有 v1 热点 API 仍以排名输出，不改变旧客户端契约。撤回和许可读取继续经过 publication 层。

精选是另一道质量筛选：保留五维评分和两次评分、噪声压制、安全边界，突出严重性、可信来源、合作竞争格局与社会影响。T1=60、T1_5=65、T2=76 保持原值，尚未做情报行业校准。请标注100–200条真实样本，按 `docs/selection.md` 校准；示例 gold 文件是虚构教学样本。

|---|---:|---|
| 国际、美国、各地区、官方、矿业、能源、金融、贸易 RSS | 380 | 已配采集地址；需逐源试抓，可能包含 Google News 搜索入口 |

| 外部结构化入口 | 24 | 默认关闭，只有入口登记，尚需授权、凭证、采集器或外部规范化脚本 |

新闻包括 BBC、Reuters、AP、Guardian、Al Jazeera、DW 等国际和美国来源；矿业能源包括 Mining.com、Mining Weekly、OilPrice、S&P Global 等，以及相关官方公告。来源网页、付费文章和搜索摘要的使用权限不能由目录替代。默认不开放全文。

JSON采集器支持字段路径、标题/摘要模板、真实日期和按环境变量引用的认证参数。配置中的 `credentialQuery` / `credentialHeaders` 只存环境变量名，密钥通过后端 collectors 凭证读取。EIA使用 `EIA_API_KEY`，FRED使用 `FRED_API_KEY`。不要把密钥写入sources.json或前端。

官方格式参考：[EIA API](https://www.eia.gov/opendata/documentation.php)、[USGS GeoJSON](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php)、[NASA EONET](https://eonet.gsfc.nasa.gov/docs/v3)。观测期与新闻发布时间并不等价：年/月统计是背景，不能当成刚发生的危机；写作要求保留日期、单位、频率、定义及修订信息。当前未实现自动油价异常检测和贸易变化率计算。

外部入口覆盖：UCDP、ACLED冲突及社会动荡；OFAC制裁；UN Comtrade贸易；WTO关税；GIE气库存；OpenSky/Wingbits航空；AIS船舶；Cloudflare互联网；abuse.ch网络威胁；预测市场；股指与ETF；宏观历史；WFP食品风险；WHO疫情；空气质量；摄像头；机场；咽喉；运输压力；能源设施；国家风险与韧性；概率预测。不同提供商的授权、付费、实时性及历史覆盖不同。

### 外部数据推送

现有 `POST /api/ingest/items` 接口使用 `Authorization: Bearer <INGEST_TOKEN>`（至少16字符），一次最多50项。先在后台启用已登记的外部来源；未知来源保持isolated等待管理员审核。规范化脚本可以提供普通文本数据，示例：

```json
{"sourceId":"intel-external-comtrade","items":[{"title":"贸易观测摘要（示例，不是真实事件）","url":"https://comtradeplus.un.org/?reporter=示例&intel_period=2026-09","publishedAt":"2026-09-01T00:00:00Z","summary":"指标、期间、数量和单位","bodyText":"规范化后的观测值、口径、对比期间与来源说明。","raw":{"dataset":"UN Comtrade","period":"2026-09","frequency":"monthly","_aihot":{"backfill":true}}}]}
```

正文上限20000字符、摘要上限2000字符。每个观测应有稳定且唯一的原始链接/观测期链接，避免不同国家、不同期间覆盖同一文章。标记历史回填，不能用抓取时间伪造新闻日期。数据推送之后仍经过筛选、归组和公开读取规则，不直接发布用户提交的文字。

## 日报与通知

沿用框架的 worker 采集、模型筛选、事件归组和报告定时生成。网页、四分类RSS、日报、公开API和MCP共享发布规则。默认日报每天北京时间08:00；最终启用前确认部署时区和报告日界。飞书精选推送沿用现有机制，不把重要性自动当作告警阈值；目前没有新增 Telegram 发送、邮件通知或浏览器推送。

`.env.example` 中采集、模型和外部通知安全阀关闭。读页面不会调用模型。先完成来源试抓和模型预算配置，再逐项启用 worker；不建议第一次把447个公开入口一起打开。采集频率RSS/Telegram60分钟、JSON180分钟，是轮询配置，不保证实时到达。
